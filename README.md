# Pereira digital twin (web viewer)

Live: https://ricardo-colombia.github.io/pereira-digital-twin/

A read-only 3D digital twin of Pereira, Risaralda (Colombia), built in Unity 6
and exported to WebGL. Terrain, about 170,000 buildings, streets, water, power
lines, street trees, population, bus routes, crashes and public Wi-Fi, each with
a provenance chip (Measured / Derived / Modelled / Illustrative).

The first load downloads about 70 MB and needs a desktop browser with WebGL 2.
This repository holds only the built player; it is not a tool for technical
advice (the slope view is not a hazard map, and building heights are estimates).

Data: FABDEM (CC BY-NC-SA 4.0, so non-commercial use), OpenStreetMap (ODbL),
Microsoft and Global Building Atlas footprints, WorldPop, UPME, datos.gov.co.
